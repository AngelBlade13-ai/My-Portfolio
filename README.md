# Bladen McKinlay Developer Portfolio

This repository contains a static HTML portfolio created for the **Job Seeking: Build a Portfolio** assignment.

The purpose of this portfolio is to present a focused set of software development projects for job seeking, interview preparation, and professional review. It highlights technical skills, project context, implementation details, challenges, and source-code access in one simple GitHub Pages-ready site.

## Assignment Context

The assignment asks students to prepare a developer portfolio that can help with job interviews and professional interactions. The portfolio should show more than a resume by giving reviewers tangible examples of:

- completed projects
- technical depth
- problem-solving ability
- communication skills
- source-code access
- professional formatting

This site was built to satisfy those goals with a clean static page that can be hosted for free through GitHub Pages.

## Portfolio Sections

The portfolio includes:

- About Me
- Skills
- Selected Projects
- Contact Information

## Featured Projects

The selected projects were chosen to show a range of frontend, backend, full-stack, tooling, database, authentication, and API experience.

### Suno Diary

A full-stack music archive and listening experience built with React, Vite, Node.js, Express, MongoDB, JWT authentication, Cloudinary, Playwright, GitHub Actions, and an Ollama-powered admin assistant.

### Movie Search Database

A Node.js and Express movie search app using EJS, MongoDB, Mongoose, bcrypt, sessions, and the TMDB API. Users can register, log in, search movies, view details, and save favorites.

### Song Catalog Import Assistant

A Python workflow tool that prepares song metadata for import into the Suno Diary catalog. It handles validation, slug normalization, duplicate detection, JSON exports, Markdown reports, Cloudinary support, and website-ready output.

### Finance Tracker

A Next.js and Firebase finance dashboard with Google sign-in, Firestore-backed user data, income and expense tracking, category totals, charting, and Firestore security rules.

### NextHaul Shopping App

A React and Strapi e-commerce demo with product browsing, category filtering, Redux cart state, fallback product data, checkout behavior, and Stripe test-mode support.

## How To View Locally

Open `index.html` directly in a browser.

No build step is required because this is a static HTML/CSS/JavaScript page.

## GitHub Pages Setup

After pushing this repository to GitHub:

1. Open the repository on GitHub.
2. Go to `Settings`.
3. Go to `Pages`.
4. Under `Build and deployment`, choose `Deploy from a branch`.
5. Select the `main` branch.
6. Select `/ (root)` as the folder.
7. Save.

GitHub will publish the portfolio at a URL similar to:

```text
https://AngelBlade13-ai.github.io/<repo-name>/
```
